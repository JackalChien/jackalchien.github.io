### 內容區塊

- **About** — 自我介紹、學歷、個人特質、目前專注領域
- **Journey** — 工作經歷時間軸（從航空電子轉型至 IT）
- **Certifications** — Red Hat、Cloud、Container、Network 等 21 張專業認證
- **Skills** — 完整技術棧分類
- **Contact** — 聯絡方式
